# Story 1.2: Pop-CLI Installation System

## Status

Approved

## Story

**As a** Kit-Dot user,  
**I want** a reliable Pop-CLI installation system that leverages existing platform detection to install blockchain node management tools,  
**so that** I can launch blockchain nodes with minimal setup regardless of whether Rust is pre-installed on my system.

## Acceptance Criteria

1. Pop-CLI installer must leverage existing platform detection from Story 1.1 (Linux/macOS/Windows/WSL)
2. **CORRECTED**: Installer must use source compilation with degit → git clone fallback strategy
3. Installation must utilize existing Rust installation from Story 1.1 when available
4. Installation failures must be handled gracefully with clear error messages and recovery guidance
5. Tool PATH management must configure `~/.kit-dot/tools` directory correctly
6. PopCliManager must provide interface for executing pop-cli commands with chain features

## Implementation Tasks

- [x] **Create PopCliInstaller with platform detection integration**

  - Import platform utilities from Story 1.1
  - Implement multi-strategy installation (binaries → cargo → source)
  - Use chain-only features: `--no-default-features --features chain`

- [x] **Configure tool PATH management**

  - Install to `~/.kit-dot/tools` directory
  - Update PATH for current session
  - Verify installation with `pop --version`

- [x] **Create PopCliManager interface**
  - Provide `checkInstallation()` and `execute()` methods
  - Support `--skip-confirm` for automated chain launching

**CORRECTED APPROACH** - Source-only installation as specified by user feedback:

1. **Source compilation only** using `npx degit r0gue-io/pop-cli` for fast repository cloning
2. **Cargo build** with specific flags: `--release --no-default-features --features chain`
3. **Git clone fallback** if degit is unavailable
4. **Dependency checking** for Rust toolchain and Protocol Buffers compiler (protoc)
