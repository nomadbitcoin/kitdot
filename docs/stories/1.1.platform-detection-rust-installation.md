# Story 1.1: Platform Detection & Rust Installation with User Consent

## Status
Approved

## Story

**As a** Kit-Dot user,
**I want** platform detection and Rust installation to only occur when I explicitly request it,
**so that** I maintain control over my development environment setup and can choose when to install blockchain development prerequisites.

## Acceptance Criteria

1. Platform detection (Linux/macOS/Windows/WSL) only runs when explicitly requested by user
2. Rust installation only occurs when user explicitly consents during init flow prompt
3. When user chooses to install, clear time warnings are provided (5-15 minutes for Rust compilation)
4. When user skips installation, helpful guidance is shown for future manual installation
5. Existing `kit-dot init` command flow remains unchanged (no breaking changes)
6. Platform verification and Rust installation progress follows existing CLI UX patterns (ora spinners, chalk colors)
7. Installation consent is stored for future use by node command functionality
