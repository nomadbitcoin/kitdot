# Story 1.1: Init Command Integration & Tool Installation Consent Flow

## Status
Draft

## Story

**As a** Polkadot dApp developer using `kit-dot init`,
**I want** to be prompted whether to install optional blockchain development tools during project setup,
**so that** I can choose to set up my development environment completely or defer tool installation for later.

## Acceptance Criteria

1. After template selection, user is prompted about optional development tools installation
2. User can choose to install tools immediately or skip installation
3. When user chooses to install, clear time warnings are provided (5-15 minutes)
4. When user skips, helpful guidance is shown for future tool installation
5. Existing init command flow remains unchanged (no breaking changes)
6. Installation progress follows existing CLI UX patterns (ora spinners, chalk colors)
