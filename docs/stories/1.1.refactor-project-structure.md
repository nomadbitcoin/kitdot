### Architecture Context

**Source Tree Information [Source: docs/ui-architecture/project-structure-standards.md]:**

- Current monorepo structure enforces /front directory for frontend applications
- Standard structure includes contracts/, cloud-functions/, docs/, and package.json at root
- Frontend templates must conform to CLI expectations with specific naming conventions
- Project type affects directory structure and template selection

**CLI Responsibilities [Source: docs/ui-architecture/cli-architecture-principles.md]:**

- Project structure creation and enforcement
- Template copying and configuration injection
- Remote template fetching with degit
- Monorepo integration and coordination
- Template categorization and filtering

**Template Loading System [Source: docs/ui-architecture/remote-template-loading-architecture.md]:**

- Uses degit for on-demand template fetching from GitHub repositories
- Template workflow includes source resolution, fetching, file customization, and configuration injection
- Current system requires templates to be specified via registry (no fallback)
- Template loader includes Wagmi configuration injection as part of processing
